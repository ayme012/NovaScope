How to read it

      
Image plays the pictures as a video. A moving object hops between frames while background stars stay put.

      
Minus still sky subtracts the median of all frames, so anything that never moves disappears. A mover shows up as a pair: blue where it is in this frame, orange where it sits in the other frames. A star that brightens turns blue; one that fades turns orange.

      
Stack each visit adds up all images taken during one sweep of the sky. That cleans up the noise, so faint things like brown dwarfs become visible.

      
SPHEREx images come from NASA/IPAC IRSA. Star positions: ESA Gaia DR3. Names: CDS Sesame.
