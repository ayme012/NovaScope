**Instructions to Run:**
To view real data, please folow this instruction:

1. Select 'novascope'.
2. Download or clone the GitHub repository.
3. Ensure Python and the required dependencies are installed.
4. Right-click `start-novascope.bat` > Properties > General > Security > Select 'Unblock' > OK
5. Run `start-novascope.bat` on Windows.
6. Follow the instructions displayed in the Command Prompt to access the local web application.

note: Images for Banard's Star, Epsilon Indi B, WISE 0855-0714, RW Aurigae and R Draconis might unable to be shown. Please refer to the simulated version by open the "index.html" in live server.
